<summary>Project details</summary>

### [QA Automation Sample](https://github.com/Radhdyt/qa-automation-sample)
`C#` `NUnit` `Selenium` `ExtentReports`

Complete UI test suite written from scratch over a public demo storefront. Every
environment value arrives through `.runsettings`, so the same build runs locally or
against a Selenoid grid without recompiling. Nine tests, an Extent report per run,
screenshots captured on failure, and a GitHub Actions job that publishes both.

### [Digital Certificate System](https://github.com/Radhdyt/sertifikat-digital-pelatihan)
`Next.js` `TypeScript` `Supabase` `Solidity` `IPFS`

Full-stack platform for issuing and verifying training certificates as Soulbound Tokens
on Polygon, with metadata pinned to IPFS. Separate portals for admins, assessors, and
recipients, plus a public verification page that requires no login, turning a forgeable
PDF into a non-transferable on-chain credential.

**[Live demo](https://sertifikat-digital-pelatihan.vercel.app)**

### [Smart Waste Bin AI](https://github.com/Radhdyt/SmartWasteBin-AI)
`Python` `YOLOv8` `ESP32-CAM`

Real-time classification of organic and non-organic waste. Detection pipeline includes
anti-flicker smoothing, a `person` class filter to ignore passers-by, HTTP-triggered
servo control on the bin, and CSV event logging. Runs in simulation mode against a
webcam when no hardware is attached.

### [RC Session Manager](https://github.com/Radhdyt/RC-Session-Manager)
`JavaScript` `Chrome MV3` `Jest`

Chrome extension for running multiple accounts side by side. Stores and re-injects
browser cookies per profile, with a site-aware extractor for individual session tokens
and a DOM storage injector for apps that keep state outside cookies. All data stays in
IndexedDB locally. Logic is unit-tested with Jest.

### [Semantic Segmentation](https://github.com/Radhdyt/land-cover-segmentation)
`Python` `PyTorch` `U-Net`

U-Net implementation for land-cover classification on satellite imagery, built on the
LandCover.ai dataset. Uses sliding-window patch inference instead of resizing so
building and road edges stay sharp at full resolution, with resumable checkpointing.

### Experience

**Quality Assurance Intern** &middot; PT United Tractors Tbk &middot; Aug 2025

Extended the company's existing .NET test automation framework to cover 6 internal web
applications. Wrote 64 page objects and around 8,900 lines of C# following the Page
Object Model, spanning end-to-end risk-audit workflows from login and risk dashboard
through risk register, approval summary, and risk-based audit. Tests ran cross-browser
on a Selenoid grid backed by Docker, capturing video and browser logs per test case.
Environment configuration was parameterised through `.runsettings`, so the same suite ran
against any environment without code changes. Results were rendered through ExtentReports
with automatic pass/fail screenshots and download-artifact verification against the
Selenoid REST API.
